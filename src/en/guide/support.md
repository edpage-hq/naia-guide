# Need help?

## Where to ask your question

- **Project messaging**: from a project's page, it's the channel to prefer for any question about that project. Your message stays in context, with the rest of the team.
- **edPage support**: for everything else (sign-in, product, invoice, payment…), write to <support@edpage.net>. Each e-mail becomes a ticket, and your replies to support e-mails add to the same ticket.
- **My requests to edPage**: if you're a referrer, independent sales agent or influence partner, create and follow your requests from this section of your space. Your queue is handled separately, with an answer within 24 business hours.
- **Customer area**: if you're a product client (ERA, ELEIS…), the personal link sent by support lets you create and follow your requests without an account.

## What we can help you solve

| Type of request   | Examples                                                                 |
| ----------------- | ------------------------------------------------------------------------ |
| Access / sign-in  | Forgotten password, account wrongly suspended, sign-in code not received |
| Billing / payment | Invoice or receipt not received, failed online payment, refused transfer |
| Usage             | Question about a feature, unexpected behaviour                           |
| Technical issue   | Blocking error, page unreachable                                         |
| Appeal            | Refused partner code discount that you think was justified               |

Depending on the nature of your request, expect an answer within a few hours to one business day.

## Sign-in code not received

If you're waiting for a sign-in code by e-mail, check your spam folder, then click **Send a new code** (at most once a minute). A code is valid for 15 minutes.
