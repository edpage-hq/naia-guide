# Introduction

Naia est l'outil de gestion d'**edPage group**. Il réunit en un seul endroit :

- les **projets** : phases, jalons, tâches, documents, signatures et messagerie ;
- le **commercial** : codes, pistes, propositions, remises et commissions du réseau de vente ;
- la **Caisse** : encaissements, reçus, dépenses, ordres de paiement et états ;
- le **support**, les **ressources humaines**, la **paie** et la **formation** ;
- le pilotage de la **Direction** : décisions à prendre et indicateurs.

Ce guide est organisé par rôle. Chaque compte ne voit que ce qui le concerne : chaque page décrit ce que vous verrez dans votre propre espace.

### Plusieurs rôles sur un même compte

Un membre de l'équipe edPage group peut cumuler plusieurs rôles internes, par exemple chef de projet et collaborateur, ou administrateur et caissier. Ses droits sont alors l'addition de ceux de chaque rôle, et son menu regroupe toutes les rubriques correspondantes.

Les rôles externes (client, partenaire, apporteur, commercial indépendant, partenaire d'influence, contributeur externe) restent seuls sur leur compte.

Certains rôles ne peuvent pas être tenus par la même personne pour une même opération : par exemple, celui qui valide une dépense ne la paie pas. Naia vous l'indique quand une action vous est refusée pour cette raison.

## Se connecter

Il n'y a pas d'inscription libre sur Naia. Votre compte est ouvert de l'une de ces trois façons :

- **par invitation** : vous recevez un e-mail avec un lien pour activer votre compte et choisir votre mot de passe ;
- **par l'administrateur**, qui crée votre compte et vous communique vos identifiants ;
- **par candidature**, pour rejoindre le réseau commercial (commercial indépendant, apporteur d'affaires ou partenaire d'influence) : depuis la page de connexion, suivez le lien **Déposer une candidature**, puis remplissez le formulaire. Si votre candidature est acceptée, vous recevez un lien pour signer votre document et créer votre compte.

Ensuite, vous vous connectez depuis la page de connexion avec votre adresse e-mail et votre mot de passe, ou avec Google ou Apple si votre compte y est lié.

Si vous pensez devoir accéder à Naia sans avoir reçu d'invitation, contactez la personne qui aurait dû vous inviter, ou consultez la page [Besoin d'aide ?](./support).

## Votre page « Aujourd'hui »

Après connexion, vous arrivez sur **Aujourd'hui**. Cette page rassemble :

- **À traiter** : ce qui attend une action de votre part, par exemple vos tâches en cours, des dépenses à approuver, des congés à décider ou des tickets sans agent. Chaque ligne ouvre l'écran où l'action se fait ;
- **Ce mois-ci** : les quelques chiffres utiles à votre rôle ;
- selon votre rôle, vos projets récents et vos échéances de facturation.

Le menu à gauche est regroupé par domaine : Commercial, Facturation, Caisse, Équipe, Support, Direction et Administration. Vous ne voyez que les rubriques auxquelles vous avez accès.

## Sécurité du compte

### Double authentification

Si votre rôle l'exige (administrateur, Direction, responsable commercial, caissier, gestionnaire RH), Naia vous demande un second code à chaque connexion, après votre mot de passe :

- **par défaut, un code à 6 chiffres vous est envoyé par e-mail.** Saisissez-le sur l'écran qui s'affiche. Il est valable 15 minutes ; si vous ne le recevez pas, cliquez sur **Renvoyer un code** (au plus une fois par minute) et vérifiez vos courriers indésirables ;
- cochez **Se souvenir de cet appareil** pour ne plus recevoir de code sur ce navigateur pendant 30 jours. Ne le faites pas sur un ordinateur partagé ;
- si vous préférez, activez une application d'authentification (Google Authenticator, Microsoft Authenticator…) depuis **Paramètres > Sécurité** : c'est elle qui vous donnera le code, et vous ne recevrez plus d'e-mail.

Pour les autres comptes, la double authentification est facultative mais recommandée : un rappel s'affiche sur votre page « Aujourd'hui » tant qu'elle n'est pas activée.

### Paramètres de sécurité

Depuis **Paramètres > Sécurité**, vous pouvez :

- changer votre mot de passe. Les appareils mémorisés sont alors oubliés, et un code vous sera de nouveau demandé ;
- activer l'authentification à deux facteurs par application, ou ajouter une clé d'accès (passkey) ;
- consulter vos **appareils mémorisés** et en oublier un, par exemple après avoir utilisé un ordinateur qui n'est pas le vôtre ;
- voir vos sessions actives et déconnecter les autres appareils.

Depuis **Paramètres > Mon historique**, vous retrouvez les actions que vous avez faites sur Naia et vos connexions.

### Coordonnées de paiement

Si edPage group vous paie (partenaire, apporteur, commercial indépendant, partenaire d'influence), enregistrez dans votre profil votre mode de paiement préféré (mobile money ou virement) et votre numéro ou compte. Ces informations sont chiffrées ; le caissier les lit au moment de vous payer.

## Notifications et messagerie

Vous êtes notifié (icône cloche en haut de l'écran, et souvent par e-mail) aux étapes qui vous concernent : jalon atteint, document à valider, facture due, demande à décider, délai dépassé. Chaque projet a aussi une messagerie intégrée pour échanger avec les autres intervenants sans quitter Naia.

## Langue

Naia est disponible en français et en anglais. Le sélecteur de langue se trouve en haut à droite de l'écran, sur toutes les pages.
