# Besoin d'aide ?

## Où poser votre question

- **Messagerie intégrée** — depuis la fiche d'un projet, c'est le canal à privilégier pour toute question liée à ce projet : votre message reste dans son contexte, avec le reste de l'équipe.
- **E-mail de support** — pour tout ce qui ne concerne pas un projet précis (problème de connexion, invitation non reçue…), contactez votre administrateur edPage group.

## Ce qu'on peut vous aider à résoudre

| Type de demande        | Exemples                                                                                |
| ---------------------- | --------------------------------------------------------------------------------------- |
| Accès / connexion      | Mot de passe oublié, compte suspendu à tort, authentification à deux facteurs bloquante |
| Facturation / paiement | Facture non reçue, paiement en ligne échoué, désaccord sur un montant                   |
| Utilisation            | Question sur une fonctionnalité, comportement inattendu                                 |
| Anomalie technique     | Erreur bloquante, page inaccessible                                                     |

Selon la nature de votre demande, comptez généralement une réponse en quelques heures à un jour ouvré.

## Vous ne trouvez pas votre rôle dans ce guide ?

Consultez l'[introduction](./introduction) pour la liste des guides disponibles par rôle, ou contactez la personne qui vous a invité sur Naia (votre chef de projet ou votre apporteur d'affaires) si vous pensez ne pas avoir le bon niveau d'accès.
