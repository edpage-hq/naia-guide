# Besoin d'aide ?

## Où poser votre question

- **Messagerie du projet** : depuis la fiche d'un projet, c'est le canal à privilégier pour toute question liée à ce projet. Votre message reste dans son contexte, avec le reste de l'équipe.
- **Support edPage** : pour tout le reste (connexion, produit, facture, paiement…), écrivez à <support@edpage.net>. Chaque e-mail devient un ticket, et vos réponses aux e-mails du support complètent le même ticket.
- **Mes demandes à edPage** : si vous êtes apporteur d'affaires, commercial indépendant ou partenaire d'influence, créez et suivez vos demandes depuis cette rubrique de votre espace. Votre file est traitée à part, avec une réponse sous 24 h ouvrées.
- **Espace client** : si vous êtes client d'un produit (ERA, ELEIS…), le lien personnel envoyé par le support vous permet de créer et suivre vos demandes sans compte.

## Ce qu'on peut vous aider à résoudre

| Type de demande        | Exemples                                                                |
| ---------------------- | ----------------------------------------------------------------------- |
| Accès / connexion      | Mot de passe oublié, compte suspendu à tort, code de connexion non reçu |
| Facturation / paiement | Facture ou reçu non reçu, paiement en ligne échoué, virement refusé     |
| Utilisation            | Question sur une fonctionnalité, comportement inattendu                 |
| Anomalie technique     | Erreur bloquante, page inaccessible                                     |
| Recours                | Remise de code partenaire refusée, que vous estimez justifiée           |

Selon la nature de votre demande, comptez une réponse en quelques heures à un jour ouvré.

## Code de connexion non reçu

Si vous attendez un code de connexion par e-mail, vérifiez vos courriers indésirables, puis cliquez sur **Renvoyer un code** (au plus une fois par minute). Un code est valable 15 minutes.

## Vous ne trouvez pas votre rôle dans ce guide ?

Consultez l'[introduction](./introduction) pour la liste des guides par rôle, ou contactez la personne qui vous a invité sur Naia si vous pensez ne pas avoir le bon accès.
