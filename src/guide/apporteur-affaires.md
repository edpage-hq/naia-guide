# Guide — Apporteur d'affaires

Recommander des clients avec votre code et suivre vos commissions.

## Votre rôle

Vous recommandez des clients à edPage group ; edPage group vend et livre. Votre outil est votre **code apporteur**, de la forme `EDA-01TG4827` (votre numéro d'entrée dans votre pays, le code du pays, puis quatre chiffres). Naia l'attribue. Il est privé : vous le donnez directement aux clients que vous recommandez.

Votre page **Aujourd'hui** montre votre code et son statut, les clients que vous avez apportés, vos commissions et vos invitations. Elle ne montre ni projets, ni jalons, ni tâches : ce n'est pas votre rôle de les suivre.

## Rejoindre le réseau

1. Déposez votre candidature depuis le lien **Déposer une candidature** de la page de connexion (« Envie de rejoindre le réseau edPage ? »), en choisissant « Apporteur d'affaires ».
2. Si elle est acceptée, vous recevez par e-mail un lien personnel, valable 7 jours. Vous y vérifiez votre adresse par un code, lisez la convention d'apport jusqu'en bas, saisissez vos informations et signez avec un second code. Vous pouvez y changer le nom de votre code.
3. Une fois la convention contre-signée par edPage group, vous créez votre compte. Votre code existe, mais il est encore **inactif**.
4. Suivez votre formation (environ 1 h) depuis **Ma formation** et réussissez son quiz (80 % de bonnes réponses). Votre code devient alors actif.

Aucune commission n'est possible avant que votre code soit actif.

## Votre contrat

Votre **contrat d'apport d'affaires (CT-04)** fixe votre taux de commission (5 à 15 %). Vous le signez dans **Mes documents**, avec un code reçu par e-mail. Tant qu'il n'est pas signé, vous ne pouvez pas être rattaché à un projet.

## Votre code

- Un client qui donne votre code à sa première inscription ou à son premier devis vous est rattaché pour de bon, sur tous les produits. Un client n'a qu'un seul code.
- Un client déjà rattaché à un autre code ne peut pas vous être rattaché. Un code inactif ou suspendu ne rattache personne.
- Si un client a oublié votre code, la Direction peut le rattacher dans les 7 jours qui suivent son inscription, à condition qu'un contact avec ce client ait été enregistré par vous. Passé ce délai, ce n'est plus possible.
- Votre code ne donne pas de remise au client.

## Vos commissions

- Vous touchez une commission sur le **premier achat** de chaque client apporté, calculée sur ce que le client a réellement payé, à chaque encaissement : 10 % par défaut sur les licences ERA et ELEIS, et sur les tranches NEXTBOXX selon le barème en vigueur.
- Un remboursement ou un paiement annulé reprend la commission correspondante, déduite de votre fiche suivante.
- Le 1er de chaque mois, Naia établit votre **fiche de commissions** du mois précédent, par produit. Depuis **Commissions**, validez-la ou contestez-la sous 5 jours ouvrés ; sans réponse, elle est considérée comme validée.
- Une fiche validée est payée par la Caisse, avec le mode enregistré dans votre profil, et vous recevez son reçu.

Depuis la V3, vous ne touchez plus rien sur les projets et services d'edPage group. Les commissions déjà calculées sur d'anciens projets restent dues et figurent toujours dans votre historique.

## Inviter un client

Depuis **Inviter**, invitez un client sur Naia et suivez l'activation de son accès. C'est le seul type de compte que vous pouvez inviter.

## Grille de prix et support

- **Grille de prix** : consultez les offres de chaque produit et leur prix en vigueur, pour renseigner les clients que vous recommandez.
- **Mes demandes à edPage** : posez vos questions au support. Votre file est traitée en priorité, avec une réponse sous 24 h ouvrées.
