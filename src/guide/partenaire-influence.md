# Guide — Partenaire d'influence

Publier vos vidéos avec votre code et suivre les clients venus par lui.

## Votre espace

Vous travaillez dans l'**Espace partenaire d'influence**. Votre menu contient :

- **Espace partenaire d'influence** : votre code et son statut, vos liens personnels, les utilisations de votre code et vos vidéos ;
- **Commissions** : vos relevés mensuels ;
- **Ma formation** : la formation à valider ;
- **Mes demandes à edPage** : vos questions au support.

Vous ne voyez jamais les données des clients : seulement la liste anonyme des utilisations de votre code (date, produit, état de l'encaissement, votre part) et le compteur du mois.

## Rejoindre le réseau

1. Déposez votre candidature depuis le lien **Déposer une candidature** de la page de connexion (« Envie de rejoindre le réseau edPage ? »), en choisissant « Partenaire d'influence ».
2. Si elle est acceptée, vous recevez par e-mail un lien personnel, valable 7 jours. Vous y vérifiez votre adresse par un code, lisez la charte jusqu'en bas, choisissez votre code, saisissez vos informations et signez avec un second code.
3. Une fois la charte contre-signée par edPage group, vous créez votre compte. Votre code existe, mais il est **inactif**.
4. Suivez votre formation (environ 1 h 30) depuis **Ma formation** et réussissez son quiz (80 % de bonnes réponses). Votre code devient alors actif.

Pensez à enregistrer vos [coordonnées de paiement](./introduction#coordonnees-de-paiement) dans votre profil.

## Votre code partenaire

Votre code est de la forme `EDI-NOM`. Il est **public** : vous le diffusez dans vos vidéos.

- Il donne au client une **remise de 5 %** sur son premier achat, une seule fois. Cette remise est réservée aux clients qu'edPage group n'a jamais connus : Naia le vérifie, et la refuse à un client déjà connu (« Ce code est réservé aux nouveaux clients »).
- Le premier code actif qu'un client donne lui est rattaché pour de bon. Un client déjà rattaché à un autre code ne peut pas utiliser le vôtre, et vous ne pouvez pas utiliser votre propre code.
- Votre espace donne un **lien personnel** par produit (ERA Admissions, ELEIS CRM, pré-inscription Kura, commande sedver.com) qui pré-remplit votre code dans le formulaire.

## Vos vidéos

Publiez au moins **3 vidéos par mois** avec la mention « Code partenaire EDI-… : je touche une commission ».

Dans **Mes vidéos**, enregistrez chaque vidéo (lien et date de publication) : c'est la preuve demandée. Enregistrez-la dans les 3 jours ouvrés qui suivent la publication ; au-delà, elle est marquée « en retard » mais compte quand même. Le compteur du mois vous indique où vous en êtes. Si vous démarrez en cours de mois, le minimum complet ne s'applique pas ce mois-là.

Les vidéos doivent être publiées sur **au moins 2 canaux** par mois (YouTube, TikTok, Instagram…) : Naia déduit le canal du lien. Si vous restez **60 jours sans enregistrer de vidéo**, votre code est **mis en pause** : il n'est plus partageable (un client qui le saisit voit « Code non actif ») et vous en êtes prévenu ainsi que le responsable commercial. Il redevient actif dès votre prochaine vidéo enregistrée.

## Vos commissions

- Vous touchez une commission sur le **premier achat** de chaque client venu par votre code, calculée sur ce qu'il a réellement payé : par défaut 15 % sur les licences ERA et ELEIS, et 5 % sur chaque tranche NEXTBOXX d'un apprenant admis.
- Un client dont la remise est refusée ne vous rapporte rien. Si le refus intervient après coup (contrôle ou fraude constatée), ce qui reste de votre part sur ce client est repris sur votre relevé suivant.
- Le 1er de chaque mois, Naia établit votre **relevé** du mois précédent. Validez-le ou contestez-le sous 5 jours ouvrés ; sans réponse, il est considéré comme validé, puis payé avec son reçu.

::: warning Fraude
À la deuxième fraude constatée par la Direction sur votre code, il est suspendu automatiquement.
:::
